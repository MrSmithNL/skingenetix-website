## 2. The three classes

| Class                                | Meaning                                                                                                                   | What is offered                                                    |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **Q** required qualifier             | The claims rules need its substance (science-page template §4, the claims registers). Removing it would overstate a claim | Keep, or a rewording that keeps the substance. Never plain removal |
| **N** negative finding or limitation | A null or non-significant result, "does not show X", or a limitation ("small", "not read") that no rule requires          | Malcolm's call: remove or reword                                   |
| **T** transparency line              | A disclosure or a transparency heading. The At-a-glance lines are already ruled "stay"                                    | Keep, or remove where it is a repeat                               |

**How the recommendations were made:**

- An N item goes when no register rule needs it. That follows the spirit of ADR-2026-09-24-P.
- A Q item is only ever reworded, never removed.
- Each disclosure is kept once at the top (At a glance, as Malcolm ruled) and once in the study's own source row. Repeats elsewhere go.

## 6. Found while reading: not caveats, but they affect the answers

1. **Argireline FAQ "How long before I see results?"** says _"Continued use beyond 28 days delivers additional cumulative benefits."_ The only data past 28 days on the page is Raikou day 60, which was **not significant**.
   If C14/C15/C18/C20 remove the day-60 lines, this unsupported claim is left with nothing on the page contradicting it. It is already on the open list (Template §9, CONTENT-001); fix it in the same change.
2. **Argireline finding card 4** still cites Henseler 2023 for safety ("No significant adverse events or skin irritation in an independent split-face study"), although Henseler left the table. It is the same orphan-citation problem as C15, and the same fix: link it to PubMed.
3. **Rows that support no claim on the page.** The Lipotec 2013 row (7-day, 2%) backs no statement on the Argireline page any more. If C19 goes, the Hoppel 2015 row backs nothing either. Template §4 rule 3 keeps only studies a claim rests on. A separate call for Malcolm, not part of this sheet.
4. **Template text to update if these answers go through:** §3.2 still says each index qualifier states "what it does not show", and §3.5 fixes the column heading (C8).
5. **C12** removes the authors' own caution about the ultrasound readings. Key figure 2 and the chart state "dermal thickness and density … about twice" from those readings. If Malcolm wants the caution kept anywhere, the honest home is the chart note, not the FAQ.
6. **Argireline FAQ "How does it work?"** does not answer its question, and it carries "gentle … generally well tolerated", which is on the open CONTENT-001 sweep. C24 only removes the hedge.
7. **PDRN FAQ "How does PDRN benefit the skin?"** says "supporting the look of a healthy moisture barrier… more radiant complexion". The register has only mouse data for barrier effects and no source for "radiant". Not a caveat. Flagged for the claims sweep.
