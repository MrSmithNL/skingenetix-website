## Belangrijke context voor volgende sessie

### Tools die werken
- `framework/shopify_auth.py` met functies `get_shopify_token(store_name)` en `shopify_api_call(store_name, query)`
- `.env` bevat `SHOPIFY_SKINGENETIX_CLIENT_ID`, `SHOPIFY_SKINGENETIX_CLIENT_SECRET`, `SHOPIFY_SKINGENETIX_STORE`
- Token cache: `.shopify_tokens/skingenetix.json` (auto refresh)

### Tools die nog niet werken
- Composio Shopify OAuth (app URL mismatch in Shopify Dev Dashboard) - niet kritiek, directe API werkt prima
- Bitwarden CLI - wacht op Malcolm's Organization setup
- GA4 / Klaviyo / Trello koppelingen - nog niet gedaan voor Skingenetix

### Belangrijke regels (vanuit CLAUDE.md skingenetix-website)
- **GraphQL first**, geen REST
- **Geen core Liquid edits**, alleen nieuwe sections/snippets
- **Alleen additive CSS**, niet theme CSS overschrijven
- **Langify** is de enige translation app, niet Shopify Translate & Adapt parallel
- **Image URL stability**: nooit originele afbeeldingen renamen of opnieuw uploaden (breekt Langify vertalingen)
- **Rate limit**: 40 req/sec op GraphQL, batch operaties throttlen
- **Bevestig altijd** voor: Liquid theme files, publishing, prijzen, deletions

### Erik's voorkeuren
- Geen em-dashes in output, gewone streepjes (uit `~/.claude/projects/-Users-erikbrandsma-Desktop-erikbrandsma-agents/memory/MEMORY.md`)
- Plain English / Nederlands, geen onnodig jargon
