## 8. Constraints learned this session

**Working with the other sessions:**

- Three sessions share ONE working tree. Always `git add <explicit paths>`, never `git add -A`.
- f3 commits only its own paths, and so does d3. Don't commit or remove their untracked handover skeletons (`2026-09-26-123413-main-1e77.md`, `2026-09-26-124923-main-7226.md`) or the `D .claude/handovers/2026-09-26-1156-main.md` deletion.

**Tools and hooks:**

- **The markdown gate lints whole staged files** (memory `the-markdown-gate-checks-whole-files`). Run `npx markdownlint --fix <files>` before committing. Keep change-log rows at exactly 3 cells (Date | What Changed | Who).
- A **Bash hook blocks non-English text**: write foreign-language copy with the Write tool (Python files or JSON), never a heredoc.
- **Any English edit to a custom-html section** (overview, evidence, usage, evidence_sources) or a phrase-table target needs `hub-i18n.py --write` before apply, or five locales keep the old text.
- **`section_css`** (new in `hub-upgrade.py`, `17a82d9`) is the only correct way to set a stock section's Custom CSS: ≤ 500 characters, no `content:`.
- **`hub_charts.py` has a reflow block for ≤ 360 px** (200% zoom, `5ba7d25`). Other pages pick it up when their charts spec is re-applied.

**Browser measurements:**

- The **clean capture** script blocks Klaviyo, forms.shopifyapps.com, shopify-forms and gtm, hides the cookie banner and un-sticks the header. It was a scratch script; rebuild it from memory `block-klaviyo-when-capturing-the-store`.
- CSS injected with `add_style_tag` loses to the page's own body `<style>` at equal specificity. Use `!important` in probes.

**Matrixyl specifics:**

- The Matrixyl pack label reads "10% MATRIXYL" on every product photo. What 10% means is parked until the formula sheet arrives (register claim 7).
- The Impact richtext accepts `<em>` inside `<h1>`, tested live.
