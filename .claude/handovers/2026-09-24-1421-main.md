## 8. Constraints learned this session

- **Cloudflare throttles Python urllib (429) while curl gets 200.** `hub-upgrade.py` now falls back to curl.
- **`}}` in custom-html** (e.g. nested `@media{…{…}}`) makes Shopify refuse the whole template. Write `} }`; `hub-i18n.py` now checks for it.
- **custom-html is one translatable blob per language.** Edit the English only through `scripts/hub-i18n.py` + `configs/hub-i18n/<page>.json`, then `--apply`.
- **The WebPage JSON-LD is localised by `hub-i18n.py`** (inLanguage, `/loc/` URL, `jsonld_i18n` name and description). Phrases never touch it.
- **Harvest translations by element** (a whole `<p>`/`<li>`) when a paragraph holds links or short connectors; by text node (12+ characters) otherwise; then check that the numbers agree.
- **A Bone FAQ needs white accordions** (`accordion_background`), or the questions vanish into the band.
- **`upload-theme-images.py` forces JPEG** (fine for photos). Upload cut-outs as WebP via the Files API directly.
- **Captures:** block `klaviyo`, `forms.shopifyapps.com` and `shopify-forms`, and un-stick `.shopify-section--header`.
- **A concurrent session works in this repo**, sweeps untracked files into its commits, and consumes `LATEST.md` at its startup. Always `git add` explicit paths; check `git log` before claiming what is committed.
- **`MEMORY.md` index limit is about 17.1 KB.** The other session adds entries too, so trim hooks rather than delete lines.
- **The Bash hook blocks some foreign text** (e.g. Italian "su"). Write multilingual content via the Write tool.
