## 8. Constraints learned this session

- **Moving a menu item to a new parent drops its translations.** Re-register them on `gid://shopify/Link/<id>` straight away:
  - de: Klinische Studien;
  - nl: Klinische studies;
  - fr: Études cliniques;
  - es: Estudios clínicos;
  - it: Studi clinici.
- **Menu tiles:**
  - They are CSS inside `brand_layout_css` in `sections/footer-group.json`, keyed by href.
  - To add one, add it to `TILES` in `scripts/menu-image-tiles.py` and push with `--css-only`. A full run also rewrites the header.
  - `ROWS` is empty now; the rows CSS is emitted only when ROWS has entries.
- **Menu selectors:** Science and Discover both carry `data-url="/pages/the-science"`, so select the menu by its text. A hidden
  (visibility:hidden) panel still has an offsetParent but reports empty innerText, so confirm with a screenshot.
- **Section Custom CSS limits:** at most 500 characters, and it refuses `content:`, `filter` and `background` with url. custom-html refuses
  `{{` and `}}`. `main-blog`'s banner is colour-only and holds the H1. `blog-posts` caps at six posts.
- **Foreign-language copy is blocked by the Bash hook.** Write it with the Write tool.
- **An unquoted heredoc runs backticks as commands.** Always use `<<'EOF'` and pass variables in through the environment. It silently skipped
  a memory edit this session.
- **Bug-prone spots:**
  - PubMed lookups blip: `build-study-page.py` retries through NCBI and Crossref.
  - For storefront fetches, use curl, not Python (Cloudflare throttles Python).
- **Commit by explicit path only:** another window's uncommitted files sit in the tree.
