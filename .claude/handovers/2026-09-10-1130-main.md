never rendered. Raw HTML cannot distinguish a painted text node from a comment. Same family as

the inverse, a false alarm. **VERIFIED 2026-09-10** — this exact mistake was made while writing this
recipe. The trustworthy check is the rendered DOM:

```
the brand_layout_css section measures height 0, and a TreeWalker over it
finds no text node whose parent is display:block
```

## 9. Constraints learned this session

- **[VERIFIED — driven live + screenshotted, 2026-08-31/09-10]** Impact headings sit inside a
  `<split-lines>` custom element that fixes line breaks **at load**. Runtime width changes do not
  reflow. In-browser experiments on these headings are actively misleading — judge from a screenshot
  after a real push.
- **[VERIFIED — DOM read, 2026-08-31]** The theme **escapes HTML** in a title setting: `<br>` renders
  as the literal characters `<br>` on the page.
- **[VERIFIED — CSS spec + live test]** A break after a **literal hyphen** is always permitted;
  `overflow-wrap`, `hyphens` and `word-break` do not govern it.
- **[VERIFIED — count mismatch, 17 crops from 11 files]** `banner-contact-sheet.py` leaves a hidden
  `.sheet/` directory of 900×486 **downscaled** tiles inside every slot. Glob top-level PNGs only.
- **[VERIFIED — measured on one 2.4:1 brief across 6 suppliers]** Luma snaps a 2.400:1 request to
  **2784×1504 = 1.851:1**. Unusable at banner ratio; composition reference only. nbp returns
  6336×2688 unasked.
- **[VERIFIED — gamma 1.55/2.10/2.60 on the same frame]** A global tone curve cannot darken a
  background: the wall is brighter than skin and a curve has no notion of subject.
- **[VERIFIED — `ls -l .husky/_`]** Husky hooks are mode 600, so **lint-staged has not run on any
  commit since 2026-08-13**. Fix is `chmod +x .husky/_/*`; not done, because it changes commit
  behaviour mid-session.
- **[VERIFIED — commits `b842c9d`, `020ebbf` landing mid-task]** Other sessions edit this repo and
  store concurrently on `main`, with no staging. Re-fetch before assuming a template is as you left it.
