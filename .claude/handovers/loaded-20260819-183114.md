## 9. Constraints learned

- **Gemini cap 250/day, shared** by NBP Pro and Flash → two products/day max.
- **Luma has no 4:5**; `image_edit` ignores `aspect_ratio` and takes one base64 `source`.
- **`square_hd` means 3072 on Seedream and 1024 on FLUX.2** — never trust a size preset.
- **google-genai 1.47 cannot pass `imageSize`** — the Gemini adapter uses raw REST.
- **`.ai` files are PDFs** (`%PDF-1.6`); `sips` refuses them on extension alone.
- **`assets/` is gitignored** — references regenerate from Drive via the script.
- `.husky` hooks are not executable; run gates by hand before committing.
