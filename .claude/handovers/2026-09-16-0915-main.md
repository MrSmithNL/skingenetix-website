## 9. Constraints learned this session

- **[VERIFIED — `grep -n "substance_block" scripts/*.py` returned only its own `def`, 2026-09-14]**
  A block that is *defined* is not a block that is *called*. `substance_block()` had never been
  invoked, so no bundle brief ever described the contents and `formulation` was dead data in every
  product config. Now wired into `build_slot` for every slot.
- **[VERIFIED — both frames read at native pixels, 2026-09-15]** A denylist of known-bad label words
  cannot hold. It caught `PORN`/`COPPEP` on U6 and passed `PDFIN`/`FORN`/`COTRER` on V5. Use
  `scripts/verify-labels.py`, which checks the EXPECTED lines are present.
- **[VERIFIED — two watchers spun 20 hours, logs zero bytes, 2026-09-15→16]** `pgrep -f "script.py"`
  matches the watcher's own command line. Never chain on it. Run sequentially, or key on
  `manifest.json`, which `generate-multi` writes once at the very end.
- **[VERIFIED — `_gemini` loops `for i in range(1, n+1)`]** Gemini bills **one request per
  candidate**, not per call. A 9-slot wave at 2 candidates costs 36 of the 250 daily requests that
  `nbp_pro` and `nbp_flash` SHARE. Past the cap both fail silently.
- **[VERIFIED — read-back after every upload]** Shopify **suffixes** on a filename collision and
  keeps serving the OLD file. A replacement must carry a different descriptive name — not a
  revision marker like `-v2`, which the SEO check flags as carrying no search value.
- **[VERIFIED — measured, 2026-09-15]** The r3 face wave bakes a **black frame ~23–32px** into some
  frames (brightness steps 2.0 → 23.1 in four pixels — a hard edge, not the intended vignette).
  Crop 36px per side before publishing. **The D4 frame already live on the Matrixyl product was NOT
  checked for this.**
- **[VERIFIED — `git commit` output, every commit]** Husky hooks are mode `0600`, so git refuses to
  run them; markdownlint and Prettier have not run since 13 August. `chmod +x .husky/_/*` fixes it.

## 10. Failed approaches (don't retry)

- **Chaining background work on `pgrep -f "generate-multi.py"`** — deadlocks on itself (see §9).
- **Snapping a hue to a target while capping the effect by saturation** — the first PDRN re-pink
  banded badly, because the glass core sits above the cap and stayed at the old hue while its
  surroundings moved. A fixed **delta** rotation across the whole warm range cannot band.
- **Auto-detecting reference boundaries on white-on-white** — failed four more times this session
  (full canvas returned; a background band mistaken for a silhouette; the reflection swallowed;
  tinted glass read as collar metal). Hand-read off a grid, then draw the box back and look.
- **Matching bbox width between a bottle and a jar reference** — compares a collar to a glass body.
  Different anatomy; the result looked plausible and was wrong.
- **Composing commit messages inline with a nested heredoc** — done twice in one day; the shell
  concatenates rather than nests and the script lands in the commit message. Write the message to a
  file and use `-F`.
