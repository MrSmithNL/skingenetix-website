```bash
from PIL import Image

```

## 9. Constraints learned this session
- **[VERIFIED — read the theme CSS + measured the live DOM at 390/768/1024/1180/1440/1920]** The banner box is a **fixed pixel height** (375/400/440) across a full-bleed width; its aspect runs ~1.0:1 to ~5.8:1. Widen the master; never rely on a single crop.
- **[VERIFIED — 422 response body]** Shopify rejects the `custom-html` `html` setting if it contains `{{` or `}}`. Minified CSS produces `}}` whenever a rule closes inside a media query.
- **[VERIFIED — `document.querySelectorAll` returned 0]** `/pages/brightening-glow`'s `hero_image_position` targets a **stale template id** and matches nothing; its image is centre-cropped, silently.
- **[VERIFIED — requested 1600×988 against an 848px master, got 1600×533]** Shopify **will not upscale** and silently ignores the crop rather than erroring.
- **[VERIFIED — all 40 candidates, then again at render size]** In a Class A frame an unspecified label is an **invented** one.
- **[VERIFIED — three consecutive waves]** FLUX.2 renders printed graduation digits despite explicit negatives, and returns 1 candidate per call regardless of `--candidates`.
- **[HYPOTHESIS — unverified]** Luma being weakest on branded work is drawn from **one session's** candidates (wrong helix marks, wrong collar metal). Consistent with `image-backend-facts` but not measured across waves. Do not treat as settled.
- **[VERIFIED — Malcolm, 2026-08-24]** Headers must match the site's standard height. He rejected the taller variant on sight.

## 10. Failed approaches (don't retry)
- **`image_size: "auto"`** to avoid cropping → header taller than the rest of the site, and the image is a grid item spanning every row so `auto` = as tall as the text; `cover` then crops the **sides**.
- **Specifying only the hero bottle's label** in a multi-product Class A frame → every engine rendered all three labels and invented the rest: **`PORN SKIN REPAIR`**, twice, at full resolution.
- **Naming the misread word in the negative list** → Luma has no negative field, so it lands in the prompt body. Use positive letter-by-letter spelling instead.
- **`flat_backdrop` for a mottled backdrop edge** → its straight-line ramp cannot follow a gradient that rises then falls; washed the far edge several levels too light. Use `profile_smooth`.
- **Mirror-tiling skin or near-black** → drew a visible diamond / vertical lines. Use `scatter` there.
- **Extending a subject that touches the edge** by shearing its 1-D profile → reads as a smeared arm (Malcolm called it out). Let it curve out of frame and fade into shadow instead.
- **Iterating on 100% artifacts** → mirror seams, join steps and faint garbled engraving all vanish in the downscale to a 440px band. Judge at render size *first*.
- **A CDN crop sized from the viewport** → asks Shopify to upscale, which it silently ignores. Size from the master's own height.
