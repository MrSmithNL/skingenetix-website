## 9. Constraints learned this session

- **[VERIFIED — read every `product_tight.png` in `assets/images/_refs-2026-08-19/`, 2026-09-11]**
  The glass is **FROSTED on all nine products** and never varies. The **CONTENTS** give the
  apparent colour: colourless (Matrixyl/Glutathione/Acetyl serums), tinted translucent (Copper
  Peptide/PDRN serums), opaque (all four cream jars). **Never take a container's colour from the
  `product_desc` prose** — that text describes the glass and the label, not the filled
  appearance. Full write-up:
  `memory/the-glass-is-frosted-the-contents-give-the-colour.md`.
- **[VERIFIED — render, 2026-09-11]** A negative will not hold a count. `duplicate products` was
  in the negative and a two-product brief still returned three bottles, because "{A} at the
  centre" implies a symmetric row. The number must be asserted positively.
- **[VERIFIED — inspected generated text, 2026-09-11]** A separation clause must be true of
  **every product it names**. Computed per bundle it described a pale ice-blue jar of cream as
  "the same neutral white frosted glass … water-clear colourless liquid". Now computed per
  colour cluster.
- **[VERIFIED — three observed failures, 2026-09-12/13]** "Has the run finished?" is not
  reliably inferable from the filesystem. `manifest.json` fires early (a smoke test writes one);
  exact `slots × 8` hangs forever on a supplier drop; count-stability can pass while a slow
  supplier works. **Rebuild sheets after the run rather than trusting a live signal.**
- **[VERIFIED — `pdrn-ritual` wave, 2026-09-13]** `pdrn-ritual-model-holding-set` has **7 tiles,
  not 8** (gpt_image returned one candidate twice and would not fill on retry). On that row only,
  every column after the gap shifts — **ask for the engine name on anything picked from it.**
- **[VERIFIED — `scripts/wave-contact-sheet.py` history]** ⚠️ **Do NOT rebuild any existing
  sheet.** The nine sheets on the Desktop label rows past Z as `Z26`, `Z27` (a tile reads `Z308`
  = row Z30 column 8). The script now emits `AA`, `AB` — rebuilding would relabel and silently
  invalidate refs Malcolm has already given.
- **[VERIFIED — read-back after every upload]** Shopify **suffixes** on a filename collision and
  keeps serving the OLD file. Bundles sharing products need distinguishing names (`-duo`,
  `-routine`, `-firming`).
- **[VERIFIED — `sections/product-faq.liquid` schema]** The FAQ image is
  `product.metafields.custom.faq_image`, a **`file_reference` wanting the MediaImage GID**. A
  `shopify://shop_images/…` handle stores as a string the section cannot resolve and the FAQ
  renders nothing, with no error anywhere.
- **[VERIFIED — `git commit` output, every commit this session]** The Husky hooks are mode
  `0600` and git refuses to run them, so markdownlint/Prettier **have not run on any commit since
  13 August**. `chmod +x .husky/_/*` fixes it; not done because it is a tooling change.
