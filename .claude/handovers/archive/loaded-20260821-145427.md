## 9. Constraints learned

- **No Gemini key in this project.** `GOOGLE_AI_API_KEY` lives in
  `~/Claude Code/Projects/hairgenetix/.env`. `qa.py` accepts either name; `backends.py`
  (generation) accepts **only** `GEMINI_API_KEY`. Export both.
- **Gemini image cap 250/day**, shared by `nbp_pro` + `nbp_flash` — two full runs fit.
  Vision quota ~500/day, separate.
- **Marks are fragile in four different ways** — see §13. Assume the next tool has the bug.
- **Never rename or re-upload an existing store image** — breaks Langify
  (`.claude/rules/shopify.md` rule 7).
- **Replacing one image means re-uploading the whole set** — Shopify has no in-place swap
  that preserves order, so URLs pick up new UUID suffixes.
- Supplied ChatGPT images arrive at **1254×1254**, below Shopify's 2048 floor, so each is
  upscaled ~1.6×. Gemini's arrive at 2048 and one Malcolm supplied at 2848.
- `assets/` is gitignored and not backed up by this repo.
- `.husky` hooks are not executable — run prettier by hand before committing.
