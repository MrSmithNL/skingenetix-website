## 9. Constraints learned this session

- **Never edit theme Liquid or overwrite theme CSS** (`.claude/rules/shopify.md`). Use the
  `custom-html` section in `sections/footer-group.json`.
- **Shopify Files suffixes a same-name upload** — the handle keeps serving the OLD image. Every
  revision needs a new filename. Bit three times.
- **`upload-theme-images.py` short-circuits on a populated `uploaded_handle`** — clear it before
  re-pushing a revised plan or it silently ships the stale image.
- **Richtext strips `class`/`style` from `<a>`** → 422. Add classes at runtime instead.
- **`range` settings have a step** — `content_max_width` is min 400 / max 1200 / step 20.
- **Per-section `custom_css` is ignored by this theme** (pushed, verified, no effect).
- **`testimonials` renders its image at 40–56px** — an avatar by design.
- **`multiple-images-with-text` caps at 3 blocks.**
- **fal's content checker false-positives** on "bare shoulders", "bare skin", "collarbone".
- Type zones must be **measured**, never eyeballed (see §10).

## 10. Failed approaches (don't retry)

- **Reviews on `multi-column` as a 6-across tile grid** — replaced a layout Malcolm had already
  approved. He was explicit: the layout was right, it only needed sliding added.
- **Reviews on `shop-the-look`** — it has native arrows but forces a product card, which he then
  asked to remove. Its `product` setting takes a **handle**, not a GID (a GID renders Shopify's
  placeholder backpack labelled "Product").
- **Per-section Custom CSS** for the layout fix — ignored by this theme.
- **`<br>` in a slideshow title** — `styled-text.liquid` runs `| escape`, so it prints literally.
  Control line breaks with `content_max_width` instead.
- **Eyeballing the type zone** — I read hero image 3's clear space as being on the right; measuring
  column brightness showed it was on the left (mean 4.5, effectively pure black).
- **Briefing "no makeup, bare lips, visible pores" and negating jewellery** for beauty models —
  four rounds of "not beautiful enough" were caused by my own negatives. See the memory entry.
