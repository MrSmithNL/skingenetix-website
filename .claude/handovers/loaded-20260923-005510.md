## 8. Constraints learned this session

- **[VERIFIED] An `outdated` translation is still served.** The nl `references.html` on three hubs was outdated and live: no JSON-LD at all, copper missing 2 of 9 references. Query `outdated` on translations, never just presence. Never edit and re-register an outdated value — re-translate the current English one. Memory: `an-outdated-translation-is-still-served`.
- **[VERIFIED] custom-html rejects `}}`, `{%` and `%}` as well as `{{`.** CSS nesting (`@media(...){.a{...}}`) trips it; `hub_charts.render_group()` spaces them out. `media-with-text` also wants `media_width`/`icon_width` as **numbers**, not strings. Nothing is saved when the upload fails — it is atomic.
- **[VERIFIED] The "10% off" overlay is a Klaviyo form in a shadow root.** CSS and element removal cannot hide it for screenshots; block the request: `await pg.route("**/*klaviyo*", lambda r: asyncio.ensure_future(r.abort()))`. The cookie banner and `newsletter-popup` do hide via CSS. Memory: `block-klaviyo-when-capturing-the-store`.
- **[VERIFIED] The three older hub specs are stale.** Later claim fixes changed the live pages, so re-applying `configs/hub-upgrades/{pdrn,acetyl…,copper}-research.json` would restore removed claims. The retrofit specs (`*-retrofit-2026-09-22.json`) are **additive** and take JSON-LD from the live page. The Matrixyl spec and the reviewer-synced specs are current.
- **[VERIFIED] `hub-upgrade.py --verify-live` under-reports on retrofits:** it counts literal `<h2>` only, and chart headings carry `class="h2"`, so it printed 0/0. Verify charts per locale with a direct check (chart heading text, `sgfig-table`, translated references heading, `inLanguage` + reviewer in JSON-LD).
